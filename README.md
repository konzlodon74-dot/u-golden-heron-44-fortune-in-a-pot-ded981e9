A tiny Python program (stdlib only) that writes one kind, funny fortune for the houseplant on the windowsill to `/output/entry.txt`. The fortune frames repotting as a promotion — a small joke a plant lover laughs at, with the cadence of a prediction and no doom or withering in it.

Run it with `python3 main.py`. It creates `/output/` if needed, writes exactly one line (111 characters), well within the 120-character gate, and prints that same line.
